## Продолжение

1. Обеспечить запись в Logistics: авторизовать Codex/GitHub для этого репозитория либо войти в GitHub в браузере для загрузки подготовленных файлов.
2. Разместить файлы в корне репозитория, сохранив папки; ZIP в GitHub не заменяет исходники.
3. Получить успешный CI, включая PostgreSQL и отдельные HTTP-процессы.
4. Подтвердить пространство Render, проверить существующие ресурсы, настроить пять разных секретных паролей и развернуть закрытый стенд.
5. Пройти docs/FINAL_TEST.md с разных устройств. Использовать только вымышленные данные.
