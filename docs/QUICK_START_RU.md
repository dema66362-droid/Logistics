# Первый вход в «Логистик»

Сайт: https://logistik-pilot-site.onrender.com/

Сервер уже развёрнут. Устанавливать программы и загружать код не требуется.

## Три действия

1. Откройте свой сервис Render: https://dashboard.render.com/web/srv-dbvdav6k1f9s73c7nihg. Войдите в свой аккаунт Render, если он попросит.
2. Откройте раздел **Environment**, найдите **LOGISTIK_TEST_SHIPPER_PASSWORD** и скопируйте его значение. Если оно скрыто, используйте кнопку просмотра или копирования рядом с ним. Пароль сгенерирован Render; отправлять его в чат не нужно.
3. Откройте сайт, укажите логин **pilot.shipper@example.test**, вставьте скопированный пароль и нажмите **Войти**.

Вы войдёте заказчиком. Для первой проверки подготовлен черновик **TEST-1001** с грузом «Вода техническая». Используйте вымышленные сведения.

## Что учитывать

Это закрытый учебный стенд. Промышленная приёмка, работа с реальными опасными грузами и полный сценарий на физических телефонах ещё не завершены.

После 15 минут без обращений бесплатный сервер засыпает; следующее открытие может занять около минуты. Данные сохраняются в PostgreSQL. Бесплатный срок существующей базы заканчивается **19 декабря 2026 в 11:34 по Москве**. До этой даты потребуется решить вопрос дальнейшего размещения и сохранения данных; платный тариф автоматически не подключался.

Пароль в Environment используется для первоначального создания кабинета. Если затем изменить пароль в самом приложении, для входа нужен новый пароль: перезапуск сервера не возвращает первоначальный.
