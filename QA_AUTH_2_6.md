# Результаты локальной проверки 2.6

Дата сборки: 2026-11-19.

- 31/31 автоматических тестов указанного набора — PASS.
- Отрисовка кабинетов заказчика, перевозчика, водителя в Chromium — PASS.
- Сохранены утверждённые CSS-правила из версии 2.5 (сравнение содержимого `<style>` побайтно) — PASS.
- Логин отображается отдельно, без переключателя ролей — PASS.
- Модальное окно самостоятельной смены пароля — PASS.
- Раздельные пароли для пяти тестовых аккаунтов: нельзя войти с паролем соседнего аккаунта — PASS.
- Смена пароля: требуется старый пароль и CSRF; старый пароль после смены не подходит, все ранее выданные сессии закрываются — PASS.
- Независимость данных организаций / доступность чужих заявок — проверяется действующими регрессионными тестами.

Что НЕ проверено:
- Реальная публикация на Render, постоянное хранилище PostgreSQL и доступ с физических телефонов через интернет.
- Полноценный аудит OWASP/пентест, нагрузка, восстановление после сбоев, Web Push, ДОПОГ и ЭПД.

Статус: готово для развёртывания **закрытого учебного пилота**. Для реальных грузов и персональных данных пока не разрешено.
